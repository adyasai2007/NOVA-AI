# NOVA Agents and Skills

## Custom Agent

### NOVA HR Support Agent

File:

`.agents/agents/nova_hr_agent.md`

The NOVA HR Support Agent helps employees with common HR questions such as:

- Salary
- Payroll
- Leave
- Vacation
- Attendance
- General HR support

The agent identifies the user's HR request and provides an appropriate
response using available application information.

---

## Custom Skill

### Resume Analysis Skill

File:

`.agents/skills/resume-analysis/SKILL.md`

The Resume Analysis Skill helps recruiters compare a candidate's resume
with a job description.

It can:

- Extract resume text
- Compare required skills
- Identify matching skills
- Identify missing skills
- Generate a match assessment

---

## Agent and Skill Relationship

The NOVA HR Support Agent handles conversational HR requests.

The Resume Analysis Skill provides specialized resume-screening
functionality.

Together they provide HR support and recruitment assistance within NOVA.
